# 角色资产图为人脸特写加全身三视图

`docs/adr/0066` 把角色资产图定成「正面 / 正侧 / 背面」三格横排。三视图给服装与体型，但不给下游一张可用的脸部特写；面部像素占比是身份锚定的真实变量，市面角色定妆照的通行形态是左侧人脸特写、右侧全身三位照。决定角色资产图仍为单张横版 16:9、纯白背景，版式改为：左侧人脸特写（头肩近景、正视镜头），右侧全身三视图（正面 / 正侧（90° 侧视图）/ 背面）水平排列。跨面板一致性覆盖特写与三个全身视图。衍生资产图的守卫钉住同一版式。

0066 的其余条款不变：场景 / 道具 / 商品仍各出单张图；不做裁切主图区或按格选图的补偿层；解剖防崩句与质量词不写入 prompt；宽高比必须显式指定为 16:9。多格拼贴经 i2i / r2v 继承构图的风险随面板增多而上升，与 0066 已接受的代价同族，不为特写格另开补偿层。

## 明确不采用

- **把特写与三视图拆成多张独立资产图**：仍是资产模型议题，见 0066。
- **在 prompt 里写面板宽度百分比或背景色十六进制值**：无来源的量化不写入模板，与 0066 同一纪律。
